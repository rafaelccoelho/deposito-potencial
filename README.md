# Depósito Potencial

Sistema de gestão para pequenos e médios depósitos de materiais de construção.

> 🚧 Projeto em desenvolvimento

## Sobre o projeto

O Depósito Potencial tem como objetivo centralizar as principais operações de um depósito de materiais de construção em uma única plataforma.

O projeto está sendo desenvolvido inicialmente como um projeto de estudo e portfólio, com possibilidade de evolução futura para um produto comercial.

## Principais funcionalidades

O sistema será desenvolvido progressivamente e deverá contemplar:

- Gestão de produtos
- Controle de estoque
- Clientes
- Fornecedores
- Vendas
- Orçamentos
- Compras
- Entregas
- Contas a pagar
- Contas a receber
- Relatórios e dashboards
- Integração com canais digitais
- Recursos de Inteligência Artificial

## Tecnologias

As tecnologias serão incorporadas progressivamente durante o desenvolvimento.

## Arquitetura

O projeto será inicialmente desenvolvido seguindo uma abordagem de monólito modular, permitindo evolução gradual da arquitetura conforme as necessidades do sistema.
